# Example Campaigns

Five pre-built campaign examples available as one-click chips in the web UI.
Each chip auto-fills the natural language input and can be parsed into a structured brief.

---

## 1. Viva Beverages — Summer Launch

**Chip label:** Viva Summer Launch
**Key:** `viva`

| Field | Value |
|---|---|
| Brand | Viva |
| Region | US |
| Audience | Health-conscious adults, 25–40 |
| Message | *Feel the Difference This Summer* |
| Brand colors | Green `#2ECC71`, White |

**Products**
| ID | Name |
|---|---|
| `viva_sparkling_water` | Viva Sparkling Water |
| `viva_energy_bar` | Viva Energy Bar |
